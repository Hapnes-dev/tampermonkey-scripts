# Logic Designer Import/Export — technical reference

Deep technical notes for `logic-designer-import-export/Logic-Designer-Import-Export.user.js`, plus the validator and VV Designer reference corpus maintained beside it. Current userscript version: **1.38.0**. It runs as one browser IIFE after a set of top-level pure helpers; grants are `unsafeWindow` and `GM_addStyle`. Repo-wide rules for version bumping, commit/push, and line endings live in the **root `CLAUDE.md`** and are not repeated here.

---

## 1. What it is / where it runs

The script adds portable JSON export/import and a client-side Live Simulate panel to IWMAC's VV Designer.

- Exact matches: `http://internal.iwmac.local/vv_fbx.qxs*` and `https://internal.iwmac.local/vv_fbx.qxs*`.
- `@run-at document-idle`, `@noframes`; no `@connect` and no network calls.
- Host access goes through `W`, defined as `unsafeWindow || window`.
- `LOAD_FLAG='__LDIO_LOADED'` prevents the same page-world instance from installing twice.
- The host is considered installable when `W.application`, `W.menu_main.creator`, and `W.logic_designer` exist. `installPoll` checks every **300 ms**, then calls `installMenuHooks()`.
- Import and simulation additionally require `W.logic_designer.paper.initialized`. Plant context comes from `W.query_string.plant_id`; current sketch/process context comes from `W.application`.

The file can also be loaded under Node: the browser body is guarded by `typeof window !== 'undefined' && typeof document !== 'undefined'`, and the pure helpers are exposed through `module.exports`.

## 3. Portable document model and export

`buildExportEnvelope()` wraps the exact `paper.save()` document in:

```text
format='vv-fbx-sketch', version=1, exported_at, source_plant_id,
source_sketch_id, name, block_count, connection_count,
optional generator, optional requires_processes, then sketch
```

`buildCurrentEnvelope()` refuses an absent paper or empty canvas. It preserves `paper.changed` around `paper.save()`, because the host save call clears the dirty flag as a side effect. It stamps `generator:'LDIO v1.38.0'` and obtains `requires_processes` from `listProcessDependencies()`, which deduplicates blocks whose `compile_type==='process'` and enriches them from the target palette or block data with `alias_text` and `current_revision`.

`doExport()` serializes with two-space indentation, downloads through a temporary Blob URL, and revokes it after **5000 ms**. `buildExportFilename()` emits `vv-sketch_…` in function mode and `vv-process_…` in process mode, sanitizes the name to `[a-z0-9_-]`, truncates it to **60** characters, and appends local `YYYYMMDD-HHmm`.

`doCopyJson()` produces the same envelope. `copyTextToClipboard()` uses `navigator.clipboard.writeText()` only in a secure context; otherwise it synchronously uses an off-screen `<textarea>` plus `document.execCommand('copy')`, preserving the menu click's user gesture on plain HTTP.

## 4. Menu integration

The host rebuilds its menus on mode changes, so one-time DOM insertion would disappear. `installMenuHooks()` permanently wraps `menu_main.creator.render(clear)` and, before each original render:

- Finds the `file` menu level.
- Adds a `Transfer` header and `file_ldio_export`, `file_ldio_import`, `file_ldio_copy` items if export is absent.
- Adds a `Simulate` header and `file_ldio_sim`.
- Adds top-level `ldio_sim_top` last, labelled `Live Simulate`.

A capture-phase document click listener resolves `.iw_oc_menu_dropdown_item, .iw_oc_menu_level` through `data-index` into `menu_main.menu_items`, then performs the action inside the native gesture. It deliberately does not stop propagation so the host still closes the dropdown. A wrapped `application.on_menu` is the fallback; `lastHandledAt` suppresses duplicate execution for **1000 ms**. Finally, `prepare_ui_menu(paper.mode)` is attempted once so entries appear without waiting for a natural mode switch.

## 5. Import pipeline and validation boundary

`openImportPanel()` provides three input paths: a **visible** file input, drag/drop, and pasted JSON. The visible control is load-bearing: the comments record that Chrome dropped transient user activation in the old programmatic `input.click()` chain. File reads use `FileReader.readAsText`; invalid JSON stops at a toast.

`applyImport(parsed)` then runs this order:

1. Require initialized paper.
2. Call `diagnoseImport(parsed, paper.blocks || {})`. Fatal findings open `showErrorPanel()`; nothing touches the canvas. `buildImportReport()` makes the Copy Problems output self-contained with numbered fixes, a block/wire inventory, and a format card.
3. If `sketch.mode !== paper.mode`, offer a mode switch. There is no “import anyway.” Accepted switching calls `paper.set_mode(sketch.mode)` and `application.reset()`; the confirmation explicitly warns that mode switching clears the canvas.
4. Toast non-fatal diagnostic notes.
5. `normalizeSketchForLoad()` deep-copies and fills absent `override`, `runtime`, `properties`, `data`, `groups`, palette-derived `func`, palette-derived `compile_type`, and missing coordinates. Coordinate fallback is a five-column grid: `x=40+(i%5)*220`, `y=40+floor(i/5)*140`.
6. Optionally perform cross-plant rebinding on another deep copy; show binding warnings.
7. Warn about driver ids whose numeric prefix is not the current plant.
8. In the same-mode case, ask before replacing `paper.changed` content.
9. `paper.reset()`, `paper.load(sketch)`, set `paper.changed=true`, and clear `application.current_sketch`, `current_sketch_name`, and `current_process` when present. The next save is therefore Save As/new content, never an accidental overwrite.

The browser diagnostic checks envelope/bare shape, invented top-level fields, integer/unique ids, target-palette block existence, common aliases/no-equivalent types, nested housekeeping fields, empty driver arrays, crash-shaped `DELAY`, FORMULA references/input count, numeric endpoints, missing blocks, and mode-gated types. Unknown published process keys are fatal when absent from `paper.blocks`; a `requires_processes` manifest supplies their display names.

> ⚠️ The README says the panel performs “the same checks as `validate-vv-sketch.js`,” but current code does not. The standalone validator is materially stricter: among other things it checks cycles, required pins, many per-type payload rules, `func` values, self-loops, and `PULSE_COUNT`'s pin-1 source. Treat browser diagnosis as the target-palette gate and the CLI validator as the full offline contract check.

## 6. Driver-id plant rebinding and warnings

Driver ids are recognized only by a leading `/^(\d+)_/` prefix. `detectSourcePlantFromDriverIds()` returns the **first** prefix found in `data.driver_ids[]` or legacy `data.driver_id`; an envelope's `source_plant_id` takes precedence.

For a cross-plant import such as `3111_…` → `10112_…`:

- `countRebindableDriverIds()` counts exact `sourcePlant + '_'` prefixes.
- The user confirms whether the plants share a compatible unit layout.
- `rebindDriverIds()` rewrites only `data.driver_ids[]` and legacy `data.driver_id`, on a deep copy.
- `isVirtualDriverId()` excludes `/^\d+_VIRTU(?:AL|ELL)_/i`. Those ids encode source project/sketch numbers; prefix-only rewriting would create a plausible but dead reference.

`listManualRebindWarnings()` counts configured `CALENDAR`/`CALENDAR_2_0`, configured `TAGVALUE`, and VIRTUAL ids. These need target-plant dialog reconfiguration or recreation. `listForeignDriverIdPrefixes()` then groups every numeric driver prefix other than the current plant and warns that those ids will read nothing here.

> ⚠️ Calendar/tag/VIRTUAL warnings currently run only inside `sourcePlant !== currentPlant`. If no source prefix is detectable, or the envelope claims the current plant, those manual-binding warnings are not shown. The foreign-prefix scan still runs whenever a current plant id exists.

## 7. Live Simulate architecture

Live Simulate drives the host's client engine; it does not compile, save, deploy, or call a server. `openSimPanel()` closes all script instances via `ldio-sim-close-all`, removes orphan `.ldio-sim-panel` nodes, installs temporary host hooks, builds input rows, and starts `simWatchTick()` every **800 ms**.

### Hook layer

`simInstallHooks(paper)` records ownership/original values and temporarily replaces:

- `paper.get_user_input`: reads `simState.values[pointer]`; blank becomes numeric `0` and is recorded in `missing`, finite text becomes a number, other text stays a string. It writes `simulation_stack_block_values`, `simulation_user_values`, and sets `simulation_auto_proceed=true`.
- `system_dialogs.information.show`: strips HTML and collects messages instead of opening modals.
- `paper.callback`: swallows `simulation_*` events, delegates all others.
- `paper.blocks.FORMULA.sim`: locally evaluates supported PHP-like formulas by wired pin and carries per-block prior output in `formulaPrev` for the `state` variable. Unsupported grammar falls back to the host prompt path and becomes `FORMULA (manual)` in the panel.
- `paper.simulator_stop`: suppresses only host auto-clear reasons `'Timed stop'` and `'Done'`.
- `paper.__highlight_block_connection`: null-safe mirror for unconnected optional inputs.
- `paper.__blink_highlight`: catches the host's null `glow()` failure.
- Library process palette definitions with no `sim`: function-like processes call `get_user_input` for one supplied output value; zero-output effect processes complete with `true`. Injected sims are marked `__ldioInjected` and removed on close.

`simRemoveHooks()` restores or deletes each shadow according to whether the property was originally owned, restores FORMULA and information dialog hooks, and removes only sims marked as LDIO-injected.

### Running and change detection

`simRunOnce()` first calls `paper.syntax_check(true)`. A failure is snapshotted for Copy Log without simulation. A passing run mirrors host setup: reset visuals, save a stack while preserving dirty state, initialize all `simulation_*` containers, and call `paper.simulator_step()` in a synchronous loop. The guard is `max(200, simulation_steps*5)`. Results, completion order, inputs, defaults, messages, structure, and flow are stored in `simState.lastRun`.

`simFpFromDoc()` creates separate fingerprints:

- Logic: mode, connections, and blocks excluding `x`, `y`, `runtime`, `current_revision`, and `required_plant_revision`.
- Layout: `[id,x,y]` tuples.

The watcher waits for two identical polls before treating an edit as settled. With auto re-run enabled it rebuilds rows and queues a run; `simQueueRun()` debounces for **300 ms**. A layout-only move repaints. If unchanged logic loses `paper.simulation_stack`, it reruns even when auto re-run is off, so the painted view persists until Stop. `simState.stopped` suppresses that repaint.

### Formula support and limitations

`compileVvFormula()` rewrites `and`/`or`/`not`, maps an explicit function allowlist, translates `inpN` to wired inputs, rejects unknown identifiers, and executes with `new Function`. Supported helpers include math, `time`, one-character PHP-style `date` formats (`w,N,G,H,i,s,j,d,n,m,Y,y,z,U,W`), `intval`, `floatval`, `idate`, `substr`, `strpos`, `stripos`, `strtotime`, `rand`, `null`, and `state`. Boolean output is normalized to `1`/`0`.

The evaluator is deliberately a subset. `phpDate()` examines `String(fmt).charAt(0)`, so it is not a general multi-character PHP date formatter. Multi-output library processes are also approximated: the panel supplies one value per block, which therefore stands in for all outputs.

### Painting, replay, and logs

- Wire color: undefined `#BBBBBB`, true/`'ALARM'` `#1FA31F`, false/`'FALSE'` `#D64545`, other `#2C7FB8`.
- Unreached blocks get a temporary black rectangle at opacity `0.3`.
- A post-paint after **700 ms** wins over host highlight animations.
- Replay base dwell is **350 ms** per block. `DELAY_VARIABLE` adds `min(4000, seconds*80)` based on the value feeding target put 1. Total dwell is scaled to at most **9000 ms**; minimum effective dwell is **140 ms**.
- Animated wire overlays track both Raphael element and timeout, so Stop can cancel pending recoloring.
- Toasts last **4500 ms**.

`buildSimulationLog()` is the self-contained AI-facing report: result/failure, plain-language summary, translated issues, inputs/defaults, flow, messages, truncated block data, and wires. It is available through the panel and `__LDIO.getSimLog()`.

## 8. Gotchas

> ⚠️ **Never mutate the imported object in place.** Normalization and rebinding intentionally deep-copy with `JSON.parse(JSON.stringify(...))`; confirmations can be cancelled and the original parsed payload remains evidence for diagnostics.

> ⚠️ **Mode switching is destructive.** `paper.set_mode()` clears the canvas. The mode-mismatch confirmation is the only pre-switch unsaved-work gate; there is intentionally no wrong-mode load path.

> ⚠️ **Do not simplify VIRTUAL rebinding to a prefix replacement.** VIRTUAL/VIRTUELL ids contain project/sketch identity after the plant prefix. They must be recreated/rebound manually.

> ⚠️ **Closing Live Simulate must restore every host shadow.** Leaving `get_user_input`, callbacks, stop/highlight workarounds, FORMULA sim, or injected process sims installed changes the host outside the panel lifetime.

> ⚠️ **Preserve `paper.changed` around every `paper.save()` used for export, simulation, or fingerprints.** The host save call mutates dirty state.

> ⚠️ **A visible import `<input type=file>` is intentional.** Replacing it with a delayed programmatic `.click()` recreates the Chrome user-activation failure documented by the code.

- Browser diagnosis depends on the live target palette, so process availability cannot be reproduced by the static CLI validator alone.
- `parseImportPayload()` and `listUnknownBlockTypes()` are exported pure helpers but the browser import path uses `diagnoseImport()` directly.
- Stop clears results and cancels timers/overlays; replay and the watcher share state. New visual timers must be tracked or they can repaint after Stop.
- The inline replay comment says “1 s sim-time ≈ 40 ms,” but executable code uses `secs * 80`, matching the README. Trust the code.
- `copyTextToClipboard()` returns success immediately for secure-context `navigator.clipboard.writeText()` even though the promise may later reject; its catch does not retry the synchronous fallback in the same call.
- `normalizeSketchForLoad()` accepts `override/runtime/properties == null` and replaces them with `{}`. Real host exports may use empty arrays for some fields; non-null arrays pass through unchanged.
- `W.__LDIO` is a live debugging surface, not a stable external API guarantee.
