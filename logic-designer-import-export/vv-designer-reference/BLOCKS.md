# VV Designer — the complete system-block palette (host-extracted)

Every one of the **71 built-in blocks**, dumped verbatim from the live designer
palette (`logic_designer.paper.blocks`, plant 3111, 2026-07-12) — including the
host's own help texts (the toolbox **?** content: the one-line description plus
the per-pin documentation) and each block's mode gating. The raw dump is
committed as [`reference_data/palette-reference.json`](reference_data/palette-reference.json).

How to read an entry: **Toolbox name** is what a user says; **`KEY`** is what a
sketch JSON uses in `type` (with `func` verbatim as listed). *Mode* `both` =
placeable in function sketches AND process definitions; `function`/`process` =
that mode only (§9 of CLAUDE.md). Pin ids are shown as the host declares them
(`i1`…/`o1`…) — **wire `put` indexes are 0-based positions**, i.e. `i1` = put 0.

Generated by `build-blocks-md.js` from the live dump — regenerate after host updates.
