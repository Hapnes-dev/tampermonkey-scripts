AI-AGENT-INSTRUCTIONS-REVISED.txt - APPLIED, SUPERSEDED, NOT FOR PASTING
========================================================================

STATUS AS OF 2026-08-10: APPLIED.

This file used to hold a full replacement for the Microsoft 365 Copilot
Studio instructions field. That replacement is now the live content of
AI-AGENT-INSTRUCTIONS.txt, so the replacement text has been removed from
here rather than left as a second copy that would drift.

DO NOT PASTE THIS FILE INTO COPILOT STUDIO. Paste AI-AGENT-INSTRUCTIONS.txt.
There is exactly one instructions text, and that is it.

WHAT THE APPLICATION CHANGED, relative to the file it replaced:

 - Added a PRECEDENCE line, a TEXT ALIGNMENT paragraph, and the
   VENTILASJON and VENT OVERLAP blocks.
 - Tightened OUTPUT FILE, ALLOWLIST, LAYOUT, LINKING, HOUSE STYLE and
   SELF-CHECK without dropping a rule.

TWO CORRECTIONS WERE MADE WHILE APPLYING IT. Both are deliberate:

 - The revision's PRECEDENCE line listed SEVEN ranks and omitted the
   reference CLAUDE.md's panel-specific rules. The canonical list is
   EIGHT ranks - see AI-BRIEFING.txt section 0 and
   documentation-rules.json -> source_precedence - so rank 4 was inserted
   and "of the same panel type" was widened to "of the same panel and
   system type".

 - The revision reprinted the sidebar caption widths as measurements
   ("W 32, centre 1291" and "W 40, centre 1361"). They are screenshot
   readings, contradicted by Arial metrics and by the production 45 px
   A-Alarm / B-Alarm pitch. The x anchors were kept and the widths are
   now marked as estimates, matching validator rule V-P08, which reports
   width-dependent findings as warnings and never as errors.

THE FIELD'S LIMITS, which any future edit must respect:

 - The Copilot Studio instructions field caps at 8000 CHARACTERS, not
   bytes, and a CRLF working tree adds one character per line. Measure
   the worst case before editing:

     python -c "import io;t=io.open('AI-AGENT-INSTRUCTIONS.txt',encoding='utf-8').read();print(len(t)+t.count(chr(10)))"

   The applied text measures 7991 worst case. Nine characters of headroom.

 - The field rejects the characters < and >. Do not introduce either,
   including inside an example.

Because the field is effectively full, ventilation detail that will not
fit belongs in the knowledge files instead - start with
VENTILATION-COPILOT-PREFLIGHT.md, which is written to be embedded whole.
