# Tampermonkey Scripts

A collection of Tampermonkey userscripts. Click an install link below to add a script — it will auto-update whenever a new version is pushed.

> Requires the [Tampermonkey](https://www.tampermonkey.net/) browser extension.

## Scripts

| Script | Description | Install |
|---|---|---|
| [AK3 Auto Scan](ak3-autoscan/) | Automates the AK3 scanner setup workflow on IWMAC plant servers | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/ak3-autoscan/AK3-Autoscan.user.js) |
| [Rocketlane Enhancer](rocketlane-enhancer/) | Hides the Gantt calendar and adds a floating chat panel on Rocketlane | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-enhancer/rocketlane-enhancer.user.js) |
| [Rocketlane Project Notes](rocketlane-project-notes/) | Adds a writable Note column to the Rocketlane Projects list with SQL persistence and live clickable URL links | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-project-notes/rocketlane-project-notes.user.js) |
| [Oneflow + HubSpot Copy Products](oneflow-copy-products/) | Adds copy buttons on Oneflow (tilbud PDF products) and HubSpot (deal Line items card) — both copy as a bulleted list with bold headers | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/oneflow-copy-products/oneflow-copy-products.user.js) |
| [Rocketlane Day Recap](rocketlane-day-recap/) | Pick a date on the Rocketlane My Timesheet and see every IWMAC plant you worked that day — the actions you performed (colour-dot chips), an estimated time split (refined by real config commits), a 🔧 badge that expands a collapsible drawer of *what config changed* (settings, units, graphics, devices), and a 📋 **Day by category** roll-up that maps your plant time onto your Rocketlane task categories — with a ⤴ **Book day** button that writes the entries straight into the timesheet (existing task matched per discipline, detailed what-changed notes, tickbox per row) and a ⤴ **Book week** toolbar button that fills Monday–Friday at 7,5 h/day in one click, never duplicating what's already booked | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-day-recap/Rocketlane-Day-Recap.user.js) |
| [IWMAC Topology Copy](iwmac-topology-copy/) | Adds Copy Topology, Export to Excel (collapsible outline), and Show Details (auto-injects live connection-type/address/port/baud/parity/driver columns into the grid when you open Topology) to the IWMAC sys_tools topology page | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/iwmac-topology-copy/IWMAC-Topology-Copy.user.js) |
| [SQL Equipment Import](sql-equipment-import/) | phpMyAdmin floating panel: pick a GitHub-hosted driver template (or load a `.sql` from disk), edit unit rows + Modbus settings (RTU/TCP, multi-IP) in the form, and emit the full SQL ready to paste into the plant DB | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/sql-equipment-import/SQL-Equipment-Import.user.js) |
| [Rocketlane Chat Bridge](rocketlane-chat-bridge/) | Bridges Rocketlane's API to the local [Project Progress Tracker](https://github.com/Hapnes-dev/Project-Progress-Tracker) HTML page, bypassing CORS — enables chat, attachments, and notifications when the tracker is opened from `file://` | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-chat-bridge/rocketlane-chat-bridge.user.js) |
| [Rocketlane Younium Status](rocketlane-younium-status/) | Adds a Younium-logo button to the Rocketlane project nav (next to "All files") that auto-shows the plant's Younium order + subscription verdict on the button when you open the project (colored pill, no click), and opens a full status modal on click — same verdict engine as the Project Progress Tracker | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-younium-status/rocketlane-younium-status.user.js) |
| [Younium Order to Quote](younium-order-to-quote/) | Adds a "📦 Copy from order" button to the Younium quote toolbar (left of Preview & Send) — enter an order number and it copies every product onto the quote, carrying over each charge's ordered quantity and discount % (prices follow the current price list) | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/younium-order-to-quote/younium-order-to-quote.user.js) |
| [Logic Designer Section Copy/Paste](logic-designer-copy-paste/) | Copy/paste block subgraphs with internal wires + bindings (Ctrl+C/V, or Ctrl+B cursor-placed ghost paste), multi-wire many pins at once (Shift+F), sweep-cut connectors (Shift+D), drag-move + session undo (Ctrl+Z), type colors (bool/int/float/string), bulk driver_id paste, in-page project switch, sketch quick-open, a multi-line formula editor with live Verify, a saved/deployed info pill, and alarm→block highlight — on the IWMAC VV Designer (`vv_fbx.qxs`). By Henrik Monge | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/logic-designer-copy-paste/Logic-Designer-Section-Copy-Paste.user.js) |
| [Logic Designer Import/Export](logic-designer-import-export/) | Adds Export/Import sketch (JSON) + a Live Simulate panel to the VV Designer — move logic between plants with one-click driver-id rebinding (`3111_…` → `10112_…`), warnings for calendar/tag bindings and unknown process blocks, overwrite-safe save-as on the target plant, and a client-side simulator that runs the whole sketch on the canvas (values you set, FORMULA blocks evaluated locally, flow replay, AI-ready log) | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/logic-designer-import-export/Logic-Designer-Import-Export.user.js) |
| [Supermarket Superuser](supermarket-superuser/) | Power-tools for the IWMAC Supermarket parameters page (`/settings/regulators`): per-column filters, searchable unit selector, Hide 0.0, Edit mode that drag-moves parameters between Measurements ⇄ Settings (`att` r ⇄ rw) with batched save, a cross-group "Show all parameters" view, driver-parameter details editor with scaling presets, batch Plant-pri/scaling on marked rows with post-write verification, one-click copy of changes to other units, and a real .xlsx export. By ØTS/MATS/Hapnes | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/supermarket-superuser/Supermarket-superuser.user.js) |
| [IWMAC Designer Import/Export](iwmac-designer-import-export/) | Adds a "Panel JSON" section under Manage Files in the IWMAC Designer (`legacy.iwmac.local/iwmac_designer_v4`) — Export the current panel as JSON (objects, containers, graphics + base64-embedded background, plus an automatic vector trace of the background for AI reading) and Insert it into another panel or plant, with one-click driver-id plant-prefix rebinding (`10113_…` → `20044_…`) and a report of bindings that won't resolve on the target plant, plus EXPORT XLSX / EXPORT ALL XLSX buttons in the Parameter Selector popup that download a regulator's, a checkbox selection's, or every unit's full parameter list as styled Excel | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/iwmac-designer-import-export/IWMAC-Designer-Import-Export.user.js) |
