# Tampermonkey Scripts

A collection of Tampermonkey userscripts. Click an install link below to add a script — it will auto-update whenever a new version is pushed.

> Requires the [Tampermonkey](https://www.tampermonkey.net/) browser extension.

## Scripts

| Script | Description | Install |
|---|---|---|
| [AK3 Auto Scan](ak3-autoscan/) | Automates the AK3 scanner setup workflow on IWMAC plant servers | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/ak3-autoscan/AK3-Autoscan.user.js) |
| [Rocketlane Enhancer](rocketlane-enhancer/) | Hides the Gantt calendar and adds a floating chat panel on Rocketlane | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-enhancer/rocketlane-enhancer.user.js) |
| [Rocketlane Project Notes](rocketlane-project-notes/) | Adds a writable Note column to the Rocketlane Projects list with SQL persistence and live clickable URL links | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-project-notes/rocketlane-project-notes.user.js) |
| [Oneflow + HubSpot Copy Products](oneflow-copy-products/) | Adds copy buttons on Oneflow (tilbud PDF products) and HubSpot (deal Line items card) — both copy as a bulleted list with bold headers | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/oneflow-copy-products/oneflow-copy-products.user.js) |
| [Rocketlane Day Recap](rocketlane-day-recap/) | Pick a date on the Rocketlane My Timesheet and see which projects/plants you logged that day, with hours and notes | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-day-recap/Rocketlane-Day-Recap.user.js) |
| [IWMAC Topology Copy](iwmac-topology-copy/) | Adds Copy Topology, Export to Excel (collapsible outline), and Show Details (injects live connection-type/address/port/baud/parity/driver columns into the grid) buttons to the IWMAC sys_tools topology page | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/iwmac-topology-copy/IWMAC-Topology-Copy.user.js) |
| [SQL Equipment Import](sql-equipment-import/) | phpMyAdmin floating panel: load a driver-template `.sql` from disk, edit unit rows + Modbus settings (RTU/TCP, multi-IP) in the form, and emit the full SQL ready to paste into the plant DB | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/sql-equipment-import/SQL-Equipment-Import.user.js) |
| [Rocketlane Chat Bridge](rocketlane-chat-bridge/) | Bridges Rocketlane's API to the local [Project Progress Tracker](https://github.com/Hapnes-dev/Project-Progress-Tracker) HTML page, bypassing CORS — enables chat, attachments, and notifications when the tracker is opened from `file://` | [Install](https://raw.githubusercontent.com/hapnes-dev/tampermonkey-scripts/main/rocketlane-chat-bridge/rocketlane-chat-bridge.user.js) |
